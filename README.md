## Micah's Village

A open source 2d colony game in the style of Rollercoaster Tycoon that serves as a learning project and a dream game that I'd like to play


## Project Structure
```text
micahsvillage/
├── assets/          # Game assets (e.g., human_sprite.png)
├── Libraries/       # Third-party dependencies
├── build/           # Build output
└── workspace/       # source files
    ├── src/         # Source code (.cpp)
    └── include/     # Header files (.h)
```
